Accessibility Statement

RealtyPix360 is committed to ensuring digital accessibility for all

♿ WCAG 2.1 AA Compliant

Our Commitment

RealtyPix360 is committed to ensuring that our website is accessible to people with disabilities. We strive to meet Web Content Accessibility Guidelines (WCAG) 2.1 Level AA standards.

Accessibility Features

Our website includes the following accessibility features:

  • Keyboard Navigation: All functionality is available using a keyboard
  • Screen Reader Compatible: Content is structured for screen reader users
  • Clear Focus Indicators: Visible focus states for keyboard navigation
  • Alt Text: All images include descriptive alternative text
  • Color Contrast: Text meets WCAG AA contrast requirements
  • Responsive Design: Site works on all devices and screen sizes
  • Skip Links: Quick navigation to main content
  • ARIA Labels: Proper labeling for assistive technologies
  • Readable Fonts: Clear, legible typography at all sizes
  • Form Accessibility: Proper labels and error messages

Third-Party Content

Some content on our website comes from third-party services (such as Aryeo property sites, Formspree forms, and embedded maps). We work to ensure these services are accessible, but their accessibility is managed by those providers.

Ongoing Efforts

We regularly review and test our website for accessibility compliance. We:

  • Conduct regular accessibility audits
  • Test with assistive technologies
  • Follow WCAG 2.1 guidelines for new features
  • Train our team on accessibility best practices
  • Welcome feedback from users

Known Issues

We are actively working to address any accessibility issues. Currently identified areas for improvement:

  • Portfolio page dynamic loading (working with Aryeo to improve)
  • Some third-party embedded content

Compatibility

Our website is designed to be compatible with:

  • Recent versions of Chrome, Firefox, Safari, and Edge
  • JAWS, NVDA, and VoiceOver screen readers
  • Voice recognition software
  • Screen magnification software

  • Americans with Disabilities Act (ADA)
  • Section 508 of the Rehabilitation Act
  • New York Human Rights Law
